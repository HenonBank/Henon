# 🚀 VIBE-CODE v1.0 - Официальный Релиз

## 📋 Что нового в версии 1.0

### ✨ Основные возможности

#### 1. **VIBE 0.5 (Free)** - Бесплатная модель
- Полностью бесплатная модель для генерации кода
- Токены не списываются, но идут в общую статистику
- Показ экономии в реальном времени
- Идеально для тестирования и обучения

#### 2. **Размышления модели** 
- Отображение мыслительного процесса AI
- Collapsible блок "🧠 Размышления модели"
- Прозрачность принятия решений
- Лучшее понимание логики кода

#### 3. **Кнопка Publish PR**
- GitHub значок рядом с кнопкой
- Быстрый запуск workflow для создания Pull Request
- Автоматическое создание ветки и PR в выбранный репозиторий
- Интеграция с настройками чата

#### 4. **TG Бот - Авто регистрация**
- Автоматический запуск регистрации через Telegram
- Уведомления о статусе регистрации
- Код подтверждения автоматически отправляется в бота
- Поддержка @VIBE_CODE_Bot

#### 5. **Статистика токенов**
- График потребления за 30 дней
- Таблица топ пользователей
- Детальная статистика по дням
- Авто-обновление при каждом запуске
- Экономия для бесплатной модели

### 🎨 UI/UX Улучшения

- Обновленная админ-панель с полным CRUD
- Toast уведомления для всех действий
- Модальные окна для редактирования пользователей
- Статусы пользователей (active/blocked/owner)
- Поиск и фильтрация в таблицах

### 🔧 Технические улучшения

- Python скрипт `update_token_stats.py` для авто-обновления статистики
- YAML файл `token_usage.yaml` для хранения данных
- Интеграция с GitHub Actions workflow
- Поддержка множественных артефактов

## 🎯 Как использовать новые функции

### VIBE 0.5 Free
1. Откройте Settings
2. Выберите модель "🆓 VIBE 0.5 (Free)"
3. Запустите генерацию
4. Смотрите сэкономленные токены в конце ответа

### Публикация PR
1. Выберите репозиторий в настройках
2. Нажмите кнопку "Publish PR" с GitHub значком
3. Workflow автоматически создаст PR

### TG Бот
1. Войдите через GitHub
2. Введите код из @VIBE_CODE_Bot
3. Или нажмите "Start Registration" для авто-запуска
